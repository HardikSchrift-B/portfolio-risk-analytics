A finance-focused analytics project that simulates how institutional portfolio managers and risk teams monitor investments in real time. The dashboard uses live market data to evaluate portfolio performance, quantify downside risk, and visualize exposure through interactive charts.

🚀 Features
Live portfolio valuation and Profit/Loss tracking
Historical price monitoring for multiple assets
Value at Risk (VaR) estimation using historical returns
Annualized volatility analysis
Sharpe Ratio for risk-adjusted returns
Beta benchmarking against S&P 500
Maximum drawdown tracking
Correlation heatmap across holdings
Stress testing under adverse market scenarios
Interactive dashboard interface
